# ✨ Features List

## Core Features

### 🤖 Local LLM Integration
- **Ollama Integration**: Uses Ollama for local LLM inference
- **No API Keys**: No external API dependencies
- **CPU-Based**: Runs efficiently on CPU without GPU
- **Model Flexibility**: Easy to switch between different models
- **Privacy-First**: All processing happens locally

### 🔍 RAG Pipeline
- **Retrieval-Augmented Generation**: Combines retrieval and generation
- **Semantic Search**: Uses vector embeddings for similarity search
- **Context Assembly**: Intelligently combines retrieved chunks
- **Response Generation**: Generates accurate, context-aware responses
- **Similarity Thresholding**: Filters results by relevance score

### 💾 Vector Store
- **ChromaDB Integration**: Efficient vector database
- **Persistent Storage**: Data persists across sessions
- **Fast Retrieval**: Optimized similarity search
- **Metadata Support**: Stores additional document metadata
- **Collection Management**: Organize multiple knowledge bases

### 💬 Conversation Memory
- **Context Retention**: Maintains conversation history
- **Multi-Turn Dialog**: Handles follow-up questions
- **Memory Management**: Limits history to prevent overflow
- **Context Window**: Smart context window management

### 🎯 Domain-Specific Behavior
- **Knowledge Boundaries**: Only answers from ingested knowledge
- **Rejection Handling**: Politely rejects out-of-domain questions
- **Topic Detection**: Identifies available knowledge domains
- **Strict Context Usage**: Prevents hallucination
