## 🚀 Quick Start: Push to GitHub

```bash
# 1. Initialize git (if not done)
git init

# 2. Add remote
git remote add origin https://github.com/fatemeh879/chatbot.git

# 3. Add public files
git add README.md ARCHITECTURE.md FEATURES.md INSTALLATION.md GITHUB_SETUP.md requirements.txt .gitignore

# 4. Commit
git commit -m "Initial commit: Portfolio repository"

# 5. Push
git branch -M main
git push -u origin main
```

**See `GITHUB_SETUP.md` for detailed instructions.**
